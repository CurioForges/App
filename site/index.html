ATELIER / CREATIVE SYSTEM

让一句话、一段视频，
变成可以直接发布的作品

Atelier 是一套装在 Windows 上的本地创作工作台。给它一个视频、一篇素材或一个想做的题目， 它把重复的工序跑完——识别与切分、翻译、配音、字幕、封面、成片。 模型当零件用：用到的能力按需加载，不用自己拼环境、跑脚本。

下载 Windows 版 先看怎么装
  • Windows 10 / 11 · x64
  • NVIDIA 显卡 · 显存 ≥ 16 GB
  • 本地运行，不上传作品
  • 数据、权重、环境都在你选的目录

01 / 域能力

每一项是一个能力单元

看清装了哪些能力、是否在运行。四个基础域随安装包到位，两个业务域按授权启用。

  • WEB

    界面与工作台

    总览、任务、日志和设置页面；所有 HTTP 接口都由它提供。

  • SCHEDULER

    任务调度

    任务的排队、执行与状态机，发布链路也在这里。

  • PIPELINES

    创作管线

    把步骤编排成可运行的创作流程；具体管线以插件包形式加载。

  • ENGINES

    模型能力

    语音识别与分离、声纹、翻译、图像与 LLM 的本地执行入口。

  • 按授权启用

    频道监控

    频道接入、热点采集与闲时排产，为创作提供选题来源。

  • 按授权启用

    平台发布

    各平台账号登录态、发布任务与稿件回收。

02 / 一条链

外语视频 → 可直接发布的中文成片

整条链都在本机跑，中间产物留在项目目录里，哪一步不满意都能单独重跑。

  1. 切分按语义断句，去掉空白与静音
  2. 识别多语种 ASR，带时间轴与说话人
  3. 翻译跨段上下文一致，名词对照可控
  4. 配音声纹克隆，多语种合成
  5. 字幕中英双语，样式与断行可调
  6. 封面按画幅出图，文字自动避让
  7. 成片对轨、混音、导出竖屏与横屏

03 / 界面

能力、任务、日志在同一处

不跳网页、不开终端；装完直接进工作台。

04 / 开始使用

三步，装在自己的盘上

  1. 01 下载并打开

    从 Release 取最新的 atelier.exe，双击即可，无需安装程序。

  2. 02 选两个目录

    首次打开是三页设置，每页都有图解：权重放哪块盘、项目数据放哪、要不要填下载令牌（可留空）。

  3. 03 点「安装」，然后进工作台

    组件下载完会自动启动并准备运行环境，进度在卡片上；之后的更新、备份、迁移都在同一个界面里。
